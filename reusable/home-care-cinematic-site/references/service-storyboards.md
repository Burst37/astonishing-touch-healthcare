# Optional service storyboards

Only use services confirmed by the agency. These are examples, not inherited claims.

| Service | Visible action |
|---|---|
| Respite care | Family member leaves for a break; caregiver and client complete a puzzle action. |
| Companionship | Deal and play cards, share a laugh, then continue the game. |
| Personal care | Guide forearm through a cardigan sleeve and gently adjust clothing. |
| Hygiene assistance | Visible hair-brushing strokes and tidy grooming, preserving dignity. |
| Meal preparation | Prepare ingredients, then serve actual food onto a plate. |
| Light housekeeping | Wipe a surface, cut to a complete forward/back vacuum pass. |
| Laundry assistance | Remove clean laundry, fold a shirt fully, place it on a stack. |
| Medication reminders | Prompt an existing routine; client opens their own English-labeled organizer and reaches for water. No dosing advice or administration. |
| Errand assistance | Select produce, put it in a bag, release the bag into the cart, then move together. |

Use distinct clips for separate menu categories. Keep branding, talent and visual tone consistent without recycling the same action. A hero can summarize enabled services, while each chapter demonstrates one clearly.
